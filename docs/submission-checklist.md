# Submission checklist

Tick each item before submitting. Fill every placeholder with confirmed
information — do not guess deadlines, limits or people.

## Content

- [ ] Solution overview: `docs/solution-overview.md` (one page, built vs mocked
      vs roadmap, tools, synthetic-data statement).
- [ ] Prototype instructions: `docs/demo-runbook.md` (reset/seed, launch each
      role at phone width, click-by-click order, real vs mocked).
- [ ] Roadmap slide: `docs/roadmap.md`, every row labelled `Roadmap, not built`.
- [ ] Spoken script: `docs/demo-script.md`, under 5 minutes, mock screens
      announced aloud.

- [ ] No real customer, customs, payment or SIM data visible.
